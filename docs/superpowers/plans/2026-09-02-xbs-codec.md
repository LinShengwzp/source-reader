# XBS Codec Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将旧 `src/utils/xbsTool/xbsTools.ts` 中真正需要的 XBS/XXTEA 二进制兼容逻辑迁移到纯 Dart，并用旧实现生成的固定 known-answer vectors 锁定逐字节兼容性。

**Architecture:** 新 codec 只接受/返回 `Uint8List`，不解析 JSON、不读文件、不访问 Flutter Widget 或数据库。JSON 文本与 `SourceDocument` 的转换继续由现有 `source_json_codec.dart` 负责，文件选择以后单独组合这两层。

**Tech Stack:** Dart 3.13、`dart:typed_data`、`flutter_test`。不新增第三方加密依赖。

**Spec:** `docs/revival/architecture.md`

## Global Constraints

- 只在 `revival/flutter-workbench` 实施。
- 不修改旧 `src/utils/xbsTool/xbsTools.ts`，它只作为 2023 行为基准。
- 新 codec 必须逐字节兼容旧 XXTEA key、little-endian word packing、32-bit unsigned overflow 和原始长度尾标。
- XBS 层不得依赖 JSON、SourceDocument、Flutter UI、文件系统、SQLite。
- 不迁移旧 `timeTools`、JSON helper 或 PKCS#7 分支。
- 非法 XBS 输入抛 `FormatException`；空明文编码抛 `ArgumentError`，与旧实现无法编码空 payload 的行为保持一致。
- 新增业务注释使用中文。
- 禁止顺手重构其他 codec 或旧项目。

### Task 2: 实现纯 Dart XBS/XXTEA codec

**Files:**
- Create: `app/lib/features/sources/codec/xbs_codec.dart`

**Interfaces:**
- Consumes: Task 1 固定 vectors。
- Produces:
  - `Uint8List encodeXbs(Uint8List sourceBytes)`
  - `Uint8List decodeXbs(Uint8List encryptedBytes)`

- [ ] **Step 1: 实现固定 key 与 32-bit arithmetic helpers**

固定 key bytes 必须与旧实现完全一致：

```text
e5 87 bc e8 a4 86 e6 bb bf e9 87 91 e6 ba a1 e5
```

Dart `int` 不会像 JS `Uint32Array` 自动溢出，因此所有 XXTEA 加减和左移结果必须显式 `& 0xffffffff`。

- [ ] **Step 2: 实现 little-endian bytes <-> uint32 words**

禁止使用宿主端序隐式转换。每个 word 明确按：

```text
b0 | b1 << 8 | b2 << 16 | b3 << 24
```

读取，写出反向拆分。

- [ ] **Step 3: 实现 XXTEA encrypt/decrypt words**

默认 rounds：

```dart
6 + (52 ~/ wordCount)
```

delta：

```text
0x9e3779b9
```

算法必须复刻旧 `btea` 与 `mx`，不加入新的 padding 模式。

- [ ] **Step 4: 实现 XBS wrapper encode**

规则：

1. 空 payload 抛 `ArgumentError`。
2. 将 payload 用 `0x00` 补至 4 字节边界。
3. 追加 4 字节 little-endian 原始 payload 长度。
4. 对整个 buffer 执行 XXTEA encrypt。

- [ ] **Step 5: 实现 XBS wrapper decode**

规则：

1. encrypted length 必须 `>= 8` 且为 4 的倍数，否则 `FormatException`。
2. XXTEA decrypt。
3. 最后 4 字节按 little-endian 读取原始长度 `m`。
4. 令 `n = encrypted.length - 4`，必须满足 `n - 3 <= m <= n`，否则 `FormatException`。
5. 返回前 `m` 字节。
6. 为兼容旧 XBS，不额外要求零 padding 字节必须为 0。

- [ ] **Step 6: 确认 GREEN**

CI 必须：

```text
flutter analyze  PASS
flutter test test/features/sources/codec/xbs_codec_test.dart  PASS
flutter test  PASS
```

- [ ] **Step 7: Commit**

```bash

git commit -m "feat: migrate legacy XBS codec to Dart"
```

## Self-Review

- 固定向量由旧 2023 实现生成，因此能防止新版算法“自己编码自己解码但格式已变”的假兼容。
- XBS 与 JSON 继续保持正交，后续导入服务只负责组合 codec。
- 没有引入第三方 crypto 包，避免实现差异和额外跨平台依赖。
- 没有扩大到数据库、文件选择或 UI。
